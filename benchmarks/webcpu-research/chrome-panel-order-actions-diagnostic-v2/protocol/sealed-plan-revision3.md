## Five arms and attributable contrasts

- R: accepted archived implementation, newly linked only to this common final harness.
- A: unchanged-source rebuild with the same accepted recipe; retained even if R/A loaded bytes match.
- B: MC32 callback containing eight original MR4 kernel paths; retain the existing emitted indirect-kernel-call structure unless the final emitted review documents otherwise.
- Q: NEW MR4-subtile-major inline specialization: MR4 subtile -> NR8 panel -> complete KS -> K. It must use precisely P's arithmetic, bias, zero-pointer/offset handling, addressing, and stores.
- P: NR8-panel-major inline specialization: NR8 panel -> MR4 subtile -> complete KS -> K. Preserve the reviewed P implementation, with no carry.

B/Q/P retain external NC128, identical MC32 task grid and 1,924 callbacks; R/A use 15,392 MR4 callbacks. Every output retains its original KS0..10, K0..127 FP32 reduction order and separate multiply/add. Q/P source should derive from one identical body template with only loop nesting/address placement changed. The review must examine compiler-created differences, not assume source sameness proves emitted sameness.

Contrasts: B/A is batching/scheduling; Q/B is specialization plus removal of residual calls and associated contextual optimization, not pure call latency; P/Q is the panel-order implementation contrast, not isolated cache-miss causality; Q/A and P/A are net candidate contrasts. Report candidate/R too, descriptively. No ratio is corrected by subtracting A/R.

P's packed panel is 45,088 bytes, versus 721,408 bytes traversed before panel reuse in Q/B. This supports a reuse-distance hypothesis, not an L1-fit or cache-miss claim. P also changes input reuse and the delay before completing neighboring output cache-line halves. The exact V8 source enables indirect inlining by default but limits a callee to 500 wire bytes; the reviewed kernel is 818 bytes. That is conditional source evidence about one inlining route, not native-JIT observation.

## Prespecified analysis and selection

Analyze each dilation independently; no recurrence weighting, pooled dilation estimate, model extrapolation or posthoc comparator selection. Pair by root and dilation, never by sorted speed or chronology proximity. Retain all observations.

For each contrast X/Y, compute ten z[r] = log(tX[r]/tY[r]), their mean and exp(mean), plus raw ratio median, unscaled relative MAD, strict win count, each first-five/last-five point, and ten leave-one-root-out points. The process replication is the observation level; do not call all 150 timings independent. Report five adjacent-complement-pair means w[j]=(z[2j-1]+z[2j])/2 and a descriptive marginal 95% sensitivity interval `exp(mean(w) +/- t[4,0.975] * sample_sd(w)/sqrt(5))`, with independently checked critical value 2.7764451051977854. This df=4 interval is not necessarily wider, does not replace the nine prespecified primary bounds, is not multiplicity-adjusted evidence, and does not establish independence between pairs. Also report chronological/position/predecessor effects, warmup-to-primary gaps and A/R trajectories. New roots remain one host and are not guaranteed independent.

Every half-run or leave-one-root-out point is explicitly exp(mean(log ratios)) over the named subset. Unscaled relative MAD(x) is median(abs(x-median(x)))/median(x), without the 1.4826 factor. For an even-length series, median is the arithmetic mean of the two central sorted values. A strict win is ratio <1; ties do not win. Retain full returned numeric precision and apply no rounding, trimming or tolerance before admission decisions.

Prespecified inferential family: Q/A, P/A and P/Q for three dilations, nine upper bounds. For each, nominal simultaneous one-sided >=95% Bonferroni upper bound is `exp(mean(z) + t[9,1-0.05/9] * sample_sd(z)/sqrt(10))`. The independently checked df=9 critical value is 3.184113720001939 (CDF cross-check 0.9944444444444442); freeze this value and its source-only numerical check in the implementation contract. These are conditional t-model bounds: approximately independent/exchangeable, adequately behaved root log-effects are assumptions, not facts established by ten roots. Serial dependence, deterministic order effects and one-host scope can invalidate nominal coverage. Report the five-pair sensitivity rather than silently substituting its result or manufacturing an IID bootstrap. This is a small engineering screen with no promised power or subpercent precision.

Global control admission, every dilation: both A/R geometric mean and median must be in [0.98,1.02]; its raw-ratio relative MAD and R and A duration relative MADs must each be <=2%. Report first/later control strata; a direction-reversing control or materially unexplained time/order effect remains a scientific limitation and prevents claiming a settled mechanism, even when the mechanical screen passes. These are agreement/dispersion gates, not statistical equivalence proof.

Candidate X (Q or P) may advance only if ALL three dilations satisfy:

- All global source, engine, correctness, layout, schedule, resource and cleanup gates pass for the complete five-arm run
- X duration and X/A ratio relative MAD <=2%
- X/A geometric mean <=0.95, its family-adjusted upper bound <1, and at least 8/10 strict paired wins
- First-five and last-five X/A points <1 and all ten leave-one-root-out points <1

A valid but noisy P does not retroactively redefine Q's hypothesis, and vice versa; candidate-specific dispersion is prespecified. A correctness/resource/layout/unknown-outcome failure anywhere is terminal for the whole stage and admits neither candidate. If the complete experiment is valid but a candidate misses the frozen practical/stability conditions, report negative/mixed or inconclusive dispersion for that candidate, without claiming equivalence.

Panel-order evidence additionally requires all three P/Q upper bounds <1, at least 8/10 wins per dilation, P/Q relative MAD <=2%, and both half-run points <1. It supports an implementation-order effect, not a cache-level causal attribution.

Selection: if only Q qualifies, advance Q; if only P qualifies, advance P with mechanism unresolved unless P/Q also qualifies; if both qualify, choose P only when the prespecified panel-order rule qualifies, otherwise choose Q as the simpler row-major specialization.
